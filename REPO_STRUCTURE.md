# Repository Structure

This document outlines the folder structure and justifies the purpose of each critical file and directory within the Pokemon TCG RL project.

## Root Directory
- `00_DIRECTIVES.md`: The core rulebook and immutable constraints for the project.
- `01_JOURNEY_LOG.md`: An append-only chronological log of all experiments, breakthroughs, and architectural shifts.
- `CABT_ENGINE_API_DOCUMENTATION.md`: Documentation for the Kaggle `cabt` simulation engine, action spaces, and API structures.
- `pytest.ini` & `conftest.py`: Root configuration for the pytest framework, ensuring human-readable, icon-rich test summaries.

## `experiments/`
The core directory containing all isolated experiments, progressively building toward the final RL agent.

### `01_baseline/`
Contains the raw Kaggle-provided Random Agent baseline and basic engine validation logic.
- `agent/`: The Kaggle starter agent directory.
  - `main.py`: The entry point for the Random Agent.
  - `deck.csv`: The required 60-card deck submission for Turn 0.
  - `cg/`: Python API bindings for the C++ OpenSpiel engine.
  - `parser.py`: Basic Kaggle parser logic to unpack the engine's JSON observations.
- `run_local_battle.py`: A script to execute the Kaggle simulation environment (`cabt`) locally and dump `.json` replays.

### `02_behavioral_cloning/`
Phase 2.1: Teaching the model the rules of the game via supervised learning from expert replay datasets.
- `preprocess.py`: Extracts state/action pairs from Kaggle JSON replays and converts them into PyTorch tensors.
- `model.py`: Defines the `TitanTransformer` architecture (Transformer Encoder/Decoder + Pointer Network).
- `train_bc.py`: The supervised training loop that optimizes the model using Cross-Entropy loss over the expert dataset.
- `titan_agent.py`: A Kaggle-compatible inference wrapper that packages the trained BC model into a submission format.
- `shards/`: A massive directory containing the preprocessed tensor `.pt` files to prevent RAM overflow during training.

### `03_rule_based_eval/`
Phase 2.2: A robust local evaluation engine and a roster of rule-based opponents to benchmark the neural network.
- `agents/`: Contains OOP ports of various rule-based expert notebooks (e.g., `dragapult.py`, `abomasnow.py`, `iono.py`).
  - `base_agent.py`: The parent class that parses observations and handles Turn-0 deck loading.
- `evaluation/`: The multiprocessing tournament engine.
  - `match_runner.py`: A `kaggle_environments` wrapper that runs a single isolated match and reports the winner safely.
  - `tournament.py`: Uses `ProcessPoolExecutor` to run hundreds of parallel games and aggregate win rates.

### `04_ppo_training/`
Phase 3: The primary Reinforcement Learning (PPO) pipeline using an Actor-Critic architecture to train against the expert agents.
- `model_ppo.py`: Upgrades the `TitanTransformer` by adding a Value Head (Critic) while preserving the Actor weights from the BC phase.
- `env_wrapper.py`: Wraps the Kaggle `cabt` engine into an RL-compatible environment. Injects dense +1/-1 and +5/-5 Prize Card/Win rewards.
- `vec_env.py`: The paranoid `SubprocVecEnv` implementation. Uses `spawn` to create isolated multiprocessing pipes that safely parallelize the C++ engine. Features a `_handle_turn_0` interceptor to automate deck loading.
- `train_ppo.py`: The massive RL training orchestrator. Uses Generalized Advantage Estimation (GAE), Value Clipping, and NaN-safe entropy masking to train the model. Includes a validation loop against `dragapult.py`.
- `dashboard.py`: A local Streamlit application that renders real-time telemetry and rolling-average KPIs from the JSONL logs.
- `logs/metrics.jsonl`: The hyper-granular, ISO-timestamped telemetry generated by the training loop.
- `checkpoints/`: The destination for `titan_ppo_best.pt` when the validation win rate improves.

## `pokemon-tcg-ai-battle/`
The raw competition dataset and C++ source code provided by Kaggle.
- `ptcg_engine/`: The underlying OpenSpiel C++ source code for the Pokemon TCG ruleset.
- `sample_submission/`: The template required for submitting agents to the Kaggle leaderboard.
- `*Card_Data.csv`: Metadata files containing Pokemon attributes, HP, and rules text.
